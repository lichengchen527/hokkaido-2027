# 北海道 2027.02.15–02.21

兩人北海道冬季行程：札幌為基地，支笏湖冰濤祭、洞爺湖、小樽。

**網站：** https://lichengchen527.github.io/hokkaido-2027/

## 怎麼一起改

- 所有內容都在 `index.html`。
- 在 GitHub 網頁上打開 `index.html`，按右上的鉛筆圖示即可編輯，改完按 **Commit changes**，約 1 分鐘後網站會更新。
- 常改的資料都在檔案下半部的 `<script>` 裡：
  - `DAYS`：每日行程
  - `P`：地圖上的地點（名稱、座標、說明、連結）
  - `MOVES`：交通表
  - `TODO`：待辦與伴手禮
- 網頁上的勾選和住宿候選只存在各自的瀏覽器裡。想讓兩人都看到，就把它寫進 `TODO` 或 `P`。
- 想討論的事情可以開 Issue。

## 出發前要決定的事

`decide.html` 是問題包，網址是 https://lichengchen527.github.io/hokkaido-2027/decide.html

- 兩個人各自點選項，按「送到 GitHub」會開一個標題是 `[問題包回答] 名字` 的 Issue，頁面上的「兩人對照」會讀這些 Issue 並比對。
- 同一頁還有「跑空檢查」（2027 年的營業、休業、活動日期查證）和「別人怎麼玩」（影片與遊記整理）。
- 要改題目或查證結果，改 `decide.html` 下半部 `<script>` 裡的 `Q`、`PLAN`、`COST`、`CHECKS`。

營業時間、票價與活動日期都可能變動，出發前請以官方公告為準。
